# ARC-6 RoboStudio / KUKA TEC 1 Android App

ARC-6 RoboStudio is an Android teach pendant simulator for robotics and industrial automation learning. The APK is distributed under the KUKA TEC 1 project name and is presented here as an independent portfolio and demo deliverable.

## Project Identity

| Item | Details |
| --- | --- |
| Project name | ARC-6 RoboStudio / KUKA TEC 1 |
| Developer | Bhushan Hiralal Bhole |
| Platform | Android APK using WebView |
| Main domain | Robot teach pendant simulation, six-axis robot workflow, I/O and program execution |
| Release version | 1.0.0 |

## Purpose

This project demonstrates how robot jogging, point teaching, digital I/O simulation, safety states, and simple motion-program execution can be combined inside one operator-style interface. It is intended for learning, demonstration, and portfolio discussion around robotics and industrial automation concepts.
