# Documentation

This folder records documentation notes for the ARC-6 RoboStudio / KUKA TEC 1 Android teach pendant simulator.

## Published Report Assets

The latest GitHub Release includes these documentation assets:

| Asset | Purpose |
| --- | --- |
| `ARC_6_RoboStudio_Project_Documentation-v1.0.0.pdf` | Technical documentation of APK structure, WebView architecture, simulation modules, and test scope |
| `ARC_6_RoboStudio_Project_Work_Report-v1.0.0.pdf` | Portfolio-style work report explaining project purpose, implementation, learning outcomes, and future scope |

## Scope

The documentation presents the app as an educational simulator inspired by industrial robot workflows. It should not be described as official KUKA software or as a certified robot controller.
